# سجیو — دستیار صوتی فارسی

نسخهٔ ۰.۱ — اولین قدم: گوشی را روشن می‌کنی، می‌گویی «سجیو»، جواب می‌دهد.

## چه کاری می‌کند
- در حالت انتظار فقط دنبال کلمهٔ بیدارباش («سجیو») می‌گردد.
- بعد از شنیدن آن می‌گوید «بله؟» و فرمان را می‌گیرد.
- **بعد از هر جواب، ۹ ثانیه بدون گفتن «سجیو» گوش می‌دهد** — یعنی می‌توانی مثل یک آدم واقعی با او حرف بزنی و گفت‌وگو قطع نشود.
- فرمان‌های آفلاین: ساعت، تاریخ، «اسمت چیه»، «خداحافظ»، «حافظه را پاک کن».
- «یادت باشه که ...» → همان لحظه در حافظه ذخیره می‌شود و در همهٔ گفت‌وگوهای بعدی در نظر گرفته می‌شود.
- بقیهٔ سؤال‌ها را به سرویس هوش مصنوعی آنلاین می‌فرستد و جواب را با صدا می‌خواند.
- شخصیت: صمیمی، همدل، کمی شوخ، بدون توهین. اسم تو را می‌داند و حافظه را در نظر می‌گیرد.
- بعد از روشن‌شدن گوشی خودش دوباره فعال می‌شود.

## ساختن فایل APK روی ویندوز

1. **Android Studio** را نصب کن (نسخهٔ Hedgehog یا جدیدتر). همراه خودش JDK و Gradle می‌آورد.
2. پوشهٔ `zizi` را باز کن: `File → Open` و همین پوشه را انتخاب کن.
3. صبر کن Gradle sync تمام شود (اولین بار چند دقیقه طول می‌کشد و اینترنت لازم دارد).
4. از منو: `Build → Build Bundle(s)/APK(s) → Build APK(s)`.
5. فایل خروجی:
   `app/build/outputs/apk/debug/app-debug.apk`

## نصب روی گوشی Huawei nova Y70

1. APK را با کابل یا بلوتوث به گوشی منتقل کن.
2. در گوشی روی فایل بزن؛ اگر پرسید، «نصب از منابع ناشناس» را برای همان برنامهٔ فایل‌منیجر اجازه بده.
3. برنامه را باز کن، اجازهٔ میکروفون و اعلان را بده.
4. دکمهٔ **روشن کردن سجیو** را بزن.

## تنظیمات مهم روی هواوی (EMUI 12)

بدون این‌ها اندروید بعد از چند دقیقه برنامه را می‌بندد:

- **تنظیمات ← باتری ← راه‌اندازی برنامه‌ها (App launch)** ← سجیو را پیدا کن ← خاموش کن «مدیریت خودکار» و هر سه گزینه را دستی روشن کن.
- **تنظیمات ← باتری ← بهینه‌سازی مصرف باتری** ← سجیو را روی «اجازه دادن» بگذار.
- **تنظیمات ← برنامه‌ها ← سجیو ← مصرف داده** ← «داده در پس‌زمینه» را روشن کن.
- در صفحهٔ برنامه‌های اخیر، سجیو را به پایین بکش (قفل کن) تا با پاک‌کردن لیست بسته نشود.

## سرویس هوش مصنوعی

در برنامه سه فیلد هست: **آدرس سرویس**، **کلید API** و **نام مدل**.

- آدرس باید یک endpoint سازگار با OpenAI باشد، مثل:
  `https://api.gapgpt.app/v1/chat/completions`
- کلید API هم از همان سرویس گرفته می‌شود.
- نام مدل: هر چه مدل قوی‌تر باشد، سجیو باهوش‌تر و «نیکو»تر می‌شود. مثلاً `gpt-4o` یا `gpt-4o-mini`.

اگر آدرس و کلید خالی بمانند، سجیو فقط فرمان‌های آفلاین را انجام می‌دهد.

> کلید API روی خود گوشی و در SharedPreferences ذخیره می‌شود. آن را در اختیار کسی نگذار.

## ساختار کد

| فایل | کار |
|---|---|
| `MainActivity.java` | صفحهٔ تنظیمات و روشن/خاموش کردن |
| `ZiziService.java` | سرویس همیشه‌فعال: شنود، تشخیص کلمهٔ بیدارباش، پاسخ صوتی |
| `Brain.java` | شخصیت سجیو، حافظهٔ گفت‌وگو و ارتباط با سرویس هوش مصنوعی |
| `Prefs.java` | ذخیرهٔ تنظیمات و حافظه روی گوشی |
| `BootReceiver.java` | فعال‌سازی خودکار بعد از روشن‌شدن گوشی |

## قدم‌های بعدی (نسخهٔ ۰.۲)

- باز کردن برنامه‌ها با صدا
- زنگ هشدار و یادآوری

- یادگیری ترجیحات با گفتن «این را یادت نگه دار»
- کاهش مصرف باتری در حالت انتظار
